# PNAS report workspace

The [week 8 brief](../data/week8/) calls for one research question using both network and text data, a checked measurement, and a paper in the PNAS LaTeX template (six pages including references).

| Place | Use |
| --- | --- |
| `notebooks/exploration.ipynb` | Try analyses before choosing what belongs in the paper. |
| `data/dataset_1/`, `data/dataset_2/` | Store the two datasets you create, separately. |
| `notes/` | Record the question, data choices, checks, and findings. |
| `figures/` | Save figures selected for the paper. |
| `paper/` | Keep the PNAS LaTeX source and references. |

Start by writing the question in `notes/question.md` and documenting each dataset's source and contents in its own README. Keep only figures that advance the paper's single story.

The existing `data/transfermarkt-datasets/` files are left in place; the two new dataset directories are for data you create.
