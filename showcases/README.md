# Adding a showcase

Create one folder per weekly visual. Give it a readable name, for example
`week-02-mobility-patterns`.

At minimum, a showcase needs an `index.html` page. Keep any files that only that visual
uses inside its own folder. Add a card for it in the repository root `index.html` so it
appears in the public gallery.

Read [`docs/HOW_THE_SITE_WORKS.md`](../docs/HOW_THE_SITE_WORKS.md) for the full,
plain-language walkthrough.
