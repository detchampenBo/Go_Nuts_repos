Nominative determinism, n. The idea that people end up in jobs that fit their names: a sprinter called Bolt, a weatherman called Storm. It also describes how a sentence-embedding model searches Marvel’s 303 Wikipedia hero pages.

      03 — Try it

      Rename a hero

      If the name decides the rank, changing only the name should move the page. Pick a hero, keep or rewrite the description, give them a new name. Your browser swaps the name everywhere on their Wikipedia page, embeds every passage again with the same model, and ranks the page against the other 302.

      The result appears here. The first run downloads the model (about 23 MB) and the page texts; after that a rename takes a few seconds.

      05 — Why

      A name in every paragraph

      A Wikipedia page repeats its subject’s name in almost every paragraph, and the page vector is the average of its paragraphs. The name is the one thing every paragraph shares. The model has no idea that “Black Bolt” is a person rather than a black bolt, so the name’s everyday meaning gets averaged into the whole page.

      When the name describes the hero (Hawkeye, Black Cat, Moon Knight), meaning search looks clever. When it doesn’t (Deadpool, Jubilee, Black Bolt, Jessica Jones), the name drags the page away from every description of the character. Keyword search doesn’t care: “Cairo”, “Harlem” and “gamma” are rare words, and rare words are what TF-IDF rewards. The vocabulary mismatch never went away. It moved into the names.

      06 — Method and limits

      What we did, what we can’t say

      Method
        Limitations
        • We wrote the descriptions ourselves, from memory. Fans reuse Wikipedia’s vocabulary (“gamma”, “symbiote”), which helps keyword search; other people’s descriptions could shift the gap.
        • Only the hero’s name as written is replaced. Secret identities (Peter Parker, Wade Wilson) stay, so the name effect is if anything underestimated.
        • “X”, or any new name, is itself a word the model reads; replacing it changes the sentences around it.
        • The rename tool runs a compressed copy of the model in your browser, so its ranks can differ from the figures above by a few places. Before and after are both computed in the browser, so the comparison is fair.
        • One model, one way to pool passages, 56 queries. Read the medians as an honest sample, not a benchmark.
